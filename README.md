# Muluken Ugamo Portfolio Website

A modern, dynamic portfolio website built with React, Vite, and CSS Modules.  
Showcases projects, blog posts, testimonials, and includes an interactive contact form with dark mode support.

---

## Features

- Responsive design with clean, modern UI
- Dynamic Projects section with demo and code links
- Blog listing with detailed post pages using React Router
- Testimonials carousel with navigation buttons
- Interactive Contact form with validation and success message
- Dark mode toggle with theme persistence
- Smooth animations using Framer Motion
- Easy to customize with modular CSS

---

## Tech Stack

- React 18
- Vite
- React Router v6
- CSS Modules
- Framer Motion
- react-simple-typewriter
